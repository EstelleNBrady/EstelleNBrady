## Featured Projects

### RAG IT Support Chatbot (Production) — Broughton Partners
A production-grade AI assistant handling IT support for 150+ employees. Built from scratch and actively maintained.

**Stack:** Amazon Bedrock · Claude Haiku · Amazon Lex V2 · LangChain · Lambda · DynamoDB · S3 · Cognito · Jira API · CloudFormation

- Retrieval-Augmented Generation over internal IT documentation stored in an S3-backed Bedrock Knowledge Base
- Conversational memory per user via DynamoDB with session-scoped history
- Automatic Jira ticket creation with AI-generated summaries and full chat transcripts
- Google SSO via Cognito with JWT-based user identification on every ticket
- After-hours detection routes employees to on-call phone support
- Deployed via GitHub Actions CI/CD with CloudWatch observability dashboards
- Improved IT support efficiency by 30%
